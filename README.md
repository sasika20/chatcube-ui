ChatCube – Real-Time Chat Application UI

Overview

ChatCube is a responsive frontend chat application developed using HTML5, CSS3, JavaScript, jQuery, and Bootstrap. The project showcases a modern messaging interface with an intuitive user experience, responsive layouts, and reusable UI components. This repository contains my own implementation of the user interface inspired by the work I contributed to during my internship and does not include any proprietary company code.

Features
Responsive chat interface
Contact list with search functionality
Chat window with message bubbles
Modern and clean UI design
Mobile-friendly layout
Interactive frontend components
